# 闹钟 (Alarm Clock Android App)

基于 Android Jetpack Compose 与 Material 3 构建的现代闹钟应用。

## 功能特性

- ⏰ **实时时钟与看板**：醒目的大字号跳秒数字时钟，直观提示下次响铃时间与剩余倒计时。
- 🗄️ **本地持久化**：基于 Room 数据库管理闹钟列表，支持精准定时与系统休眠唤醒。
- 🔁 **自定义重复周期**：支持仅一次、工作日、周末、每天或指定任意星期。
- 🎵 **多款铃声与振动**：内置雷达、柔和、钟声、蜂鸣等提示音，支持实时试听。
- 💤 **贪睡模式**：支持 5 / 10 / 15 分钟稍后提醒。
- 🔔 **锁屏唤醒与通知交互**：支持锁屏全屏界面提醒与常驻系统通知直接操作。

## 自动构建 APK (GitHub Actions)

本项目已配置 **GitHub Actions 自动化流水线**：
1. 每当向主分支推送代码，或手动在 GitHub 仓库页面点击 **Actions** > **Run workflow** 时，系统会自动在线编译 Android 工程。
2. 编译成功后，在对应的构建记录页面的 **Artifacts** 区域即可直接下载 `AlarmClock-APK` 安装包！
3. 若在 GitHub 发布 Release，APK 文件会自动上传至 Release 附件中供直接下载安装。
